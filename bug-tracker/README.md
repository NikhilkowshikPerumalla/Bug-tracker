# 🐞 E-Bug Tracker and Solver

A full-stack bug tracking and management
application built using the MERN stack.

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication
- Axios
- CSS

## Features
- User Registration and Login
- Secure Authentication
- Report Bugs
- Track Bug Status
- Set Bug Severity
- Search and Filter Bugs
- Manage and Resolve Bugs
- Dashboard

## Project Structure

- client – React frontend
- server – Node.js backend
